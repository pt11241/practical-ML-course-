**1. Цели проекта**

- Бизнес-цель: Автоматизировать процесс оценки кредитоспособности клиентов банка для ускорения принятия решений о выдаче кредитов и минимизации дефолтов.

- Техническая цель: Разработать модель машинного обучения для мультиклассовой классификации, способную предсказывать кредитный рейтинг клиента (Poor, Standard, Good) на основе его финансовой истории и демографических данных.

- Учебная цель: Отработать навыки очистки «сырых» данных, генерации признаков (Feature Engineering) и применения ансамблевых методов (Stacking) для улучшения метрик качества.

**2. Практическая направленность**
Этот проект решает классическую задачу в сфере FinTech:
  - Скоринг в реальном времени: Модель может быть встроена в банковское приложение для мгновенной предварительной оценки заявки.
  - Сегментация клиентов: Помогает банку предлагать персонализированные условия, например, процентные ставки, в зависимости от группы риска (Good vs Poor).
  - Снижение операционных расходов: Уменьшает нагрузку на кредитных аналитиков, оставляя им для ручной проверки только пограничные случаи.

**3. Результаты (Results)**
   
Обработка данных (Data Cleaning & Preprocessing):

  - Обработан датасет из 100,000 записей со значительным количеством шума и пропусков.
  - Реализована очистка строковых данных в числовых столбцах (удаление спецсимволов, исправление опечаток).
  - Обработаны аномалии (например, отрицательный возраст или возраст > 100 лет).
  - Выполнено кодирование категориальных признаков (One-Hot Encoding) и масштабирование данных (StandardScaler).

Инжиниринг признаков:

  - Сложный строковый признак Type_of_Loan разбит на бинарные флаги, что позволило модели учитывать конкретные виды кредитной нагрузки.

Моделирование:

  - В качестве бейзлайна использована Логистическая Регрессия (Accuracy ~62%).

  - Построен сложный ансамбль (StackingClassifier), включающий Bagging, ExtraTrees, RandomForest, HistGradientBoosting и XGBoost.

Итоговая метрика:

  - Итоговая точность (Accuracy) на тестовой выборке составила ~80%.

F1-score (weighted) также составил 0.80, что говорит о хорошем балансе precision и recall для всех классов.

Модель успешно различает клиентов с низким и высоким кредитным рейтингом (наилучшие показатели для классов 0 и 1).
